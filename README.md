# Sales Performance Dashboard — FY 2024-25

## About This Project
Built a complete Sales Performance Dashboard in Microsoft Excel
after cleaning messy real world data with 255 rows across
5 categories, 4 regions and 5 salespersons.

## Tools Used
Microsoft Excel — Data Cleaning, TRIM, PROPER, ABS, IF,
SUMIF, Pivot Tables, Charts, Slicers,
Conditional Formatting

## Data Cleaning Steps Performed
- Removed extra spaces using TRIM formula
- Fixed case issues using PROPER formula
- Fixed negative values using ABS formula
- Filled blank cells using IF formula
- Removed 15 duplicate rows
- Fixed spelling mistakes using Find and Replace
- Standardised Order ID format using UPPER and SUBSTITUTE

## Key KPIs
- Total Revenue : ₹17,69,11,337
- Target Achievement : 97.46%
- Profit Margin : 20%
- YoY Growth : 2.11%
- Average Discount : 7.09%
- Total Returns : 913
